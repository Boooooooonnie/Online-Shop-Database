# Online Shop Database

A relational database project designed for an online shopping system.

The database models core e-commerce entities and relationships, including members, products, browsing activities, shopping carts, orders, transactions, and purchase records.

## Database Structure

The database contains the following tables:

| Table | Description |
| --- | --- |
| Member | Stores member information and referral relationships |
| Product | Stores product information, prices, and categories |
| Author | Associates products with their authors or creators |
| Browse | Records member browsing activities |
| Cart | Stores shopping cart information |
| Order | Records products and quantities within shopping carts |
| Transaction | Stores transaction and payment information |
| Record | Stores completed purchase records |
